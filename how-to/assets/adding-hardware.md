# Adding a hardware item

**Who can do this:** Any authenticated user with access to the target sub-organization.

## Steps

1. In the left sidebar, click **Hardware** (`/hardware`).
2. Click **Add Hardware** (top right, next to **Import**).
3. Fill in the **Add Hardware** form, organized into sections:

   **Basic Info**
   - **Sub-Organization** — required if your account has access to more than one org.
   - **Name** — required (e.g. "MacBook Pro 14").
   - **Type** — required: Laptop, Desktop, Server, Monitor, Phone, Tablet, Networking, Peripheral, or Other.
   - **Status** — optional, defaults to Active (Active / In Storage / In Repair / Retired / Disposed).

   **Device Details**
   - **Brand**, **Model**, **Serial Number**, **Asset Tag** — all optional.

   **Ownership & Purchase**
   - **Assigned To** — optional, searchable employee picker (shows "No employees yet — add employees first" if your org has none — see https://docs.itdirectory.app/how-to/assets/adding-employees).
   - **Vendor / Supplier**, **Purchase Price ($)**, **Purchase Date**, **Warranty Expiry** — all optional.

   **Notes**
   - **Notes** — optional free text.

4. Click **Add Hardware** to save.

## Finding and filtering hardware

- Use the type tabs below the page header (All / Laptop / Desktop / …) to filter by device type.
- Use the search bar ("Search by name, serial, tag…") and the **Status** dropdown to narrow the list further.
- The table paginates at 25 rows per page; use the pagination bar at the bottom.
- To edit an existing item, click its row and update the same form — the submit button reads **Save Changes** instead of **Add Hardware**.

## Notes

- You can also bulk-import hardware via the **Import** button next to Add Hardware.
- Adding hardware counts against your organization's pooled asset limit — see https://docs.itdirectory.app/how-to/settings/billing.
