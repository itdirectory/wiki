# Release Notes 1.4.0

August 1, 2026

## What's New

- Add multiple hardware items, employees, software & services, or domains at once by uploading a spreadsheet, instead of entering them one at a time. The import guides you through matching your file's columns to the right fields, shows a preview of your data before anything is saved, and reports exactly which rows were added and which need a fix. A downloadable template with example data and guidance on accepted values makes it quick to get started.
- You can now sort any item list by clicking a column heading, and choose which columns are shown using the new "Columns" button next to each list. Your column choices are remembered the next time you visit.

## Bug Fixes

- Buttons and links throughout the app now consistently show a pointer cursor on hover, and a few toolbar controls were resized so they line up properly with nearby search and filter fields.
